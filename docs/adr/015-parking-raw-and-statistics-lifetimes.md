# ADR-015: 주차 원본은 48시간, 집계 통계는 영구 보존한다

- **상태**: accepted (사용자 보존 정책 확정, 구현은 아래 단계별 진행)
- **날짜**: 2026-10-27
- **결정자**: human + agent
- **컨텍스트**: 사용자가 주차 원본은 이틀만 남기고 통계자료는 영구 보존하도록 요청했다. 현재 분석 캐시는 수명이 짧고 같은 키를 덮어쓰므로 영구 통계가 아니다. 현재 7일 추이, 14일 요일·이벤트, 21일 임계 분석, 28일 전망 및 공휴일·명시적 날짜 조회는 모두 원본에 의존한다.
- **결정**: 원본 JSON과 개별 정규화 관측은 최근 48시간을 목표로 보존한다. 10분 단위 영구 통계는 별도 일반 PostgreSQL 테이블에 저장하며 TTL·retention·자동 삭제를 두지 않는다. 원본을 다른 이름의 테이블에 그대로 복사하지 않는다. 집계·읽기 전환·검산 전에는 원본 삭제를 금지한다. 당장은 추가 전용 `0036`과 수동 DB 전용 backfill job만 제공한다.
- **근거**: 주차장별 sum/count/min/max를 보존하면 평균의 평균 오류 없이 시간·요일 통계를 재계산할 수 있다. 동일 관측 시각의 공항 합산 표본 통계는 별도 보존해 서로 다른 시각의 주차장 값을 임의로 합치지 않는다. 원관측 기준 10/50 교차와 직전 시각을 별도 보존한다. 추이에는 각 버킷의 첫/마지막 값만 남기므로 원본과 같은 임의 시각·간격 정확도를 주장할 수 없다.
- **결과 (긍정)**: 통계 수명과 캐시·원본 수명을 분리한다. 원본 지문·행 수와 다시 계산한 통계 checksum을 검증하고, 중단·재시작 시 이미 보존한 통계를 덮지 않는다. 과거 표본 수와 값의 극단이 보존된다.
- **결과 (부정)**: 48시간 밖의 개별 관측과 임의 offset의 정확한 시계열은 복구할 수 없다. 이미 발행한 버킷에 재수신·지연 수정이 들어오면 자동 가산/교체하지 않고 충돌로 보류한다. 보류 중에는 원본 보존 시간이 48시간을 넘을 수 있으며 이를 운영 상태로 드러내야 한다. 이 단계에서는 원본을 전혀 삭제하지 않는다.
- **후속**: [설계·전환 수용 조건](../architecture/parking-retention.md)의 읽기 경로 전체를 전환하고 API 해상도·coverage·원본 48시간 제한을 명시한다. Map export의 세대·고정 snapshot·커서, 최신 current, 공항/주차장 기준정보, 수집 메타데이터를 보존한 실제 DB 검산 후에만 원본 정리를 활성화한다. 두 독립 리뷰와 WSL/Docker·실제 화면 수용 및 운영 검증이 끝나기 전에는 정책 구현 전체 완료로 보고하지 않는다.
