# 전국 주차장 기능의 Transport 소유권 이전

사용자 지시로 Map의 주차장 기능을 Transport에 이식한다. Map 자료를 API/DB로 복제하지 않는다.
Map `origin/main` 8ce87ed의 `parking_lots_to_bundles`와 전국주차장표준데이터 수집을 기준으로,
기존에 설치된 `python-datagokr-api`의 `DataGoKrClient.parking`을 직접 사용한다.

전국주차장정보표준데이터는 공식 파일 다운로드를 사용한다. 포털의 CSV/JSON 다운로드 버튼과
같은 공개 다운로드 경로를 provider 라이브러리의 `parking.iter_file_pages()`로 읽으며 서비스키나
활용신청은 필요 없다. 파일 원문의 대문자 컬럼을 typed 필드에 대응하는 책임은 SDK에 둔다.
전체 건수·각 페이지 길이·다운로드 전후 메타데이터를 검산하며 포털의5만 건 상한에 걸린 자료는
완료본으로 게시하지 않는다. 기존 OpenAPI의403 이력은 보존하되 파일 수집의 선행 조건으로 삼지 않는다.

- 공항 `parking_lots`·실시간 잔여면 관측과 구분한 `public_parking_lots` 기준정보 표를 만든다.
  주차면 수·요금·운영시간·주소·전화·기준일과 원문을 저장하며 정적 주차면 수를 잔여면으로 표시하지 않는다.
- 공식 주차장 번호는 원 필드에 보존하지만 전역 고유키로 가정하지 않는다. 번호·기관 코드·정규화한
  명칭·도로/지번 주소를 함께 식별하고, 번호가 없으면 기관·명칭·주소를 사용한다. 같은 식별값의 내부 ID는
  갱신 때 보존하며 명칭·주소가 바뀌면 새 행을 만들고 이전 행도 남긴다.
- 페이지 단위 SDK 조회와 제한된 bulk upsert를 사용하고 전체 수집의 최종 검산 후 같은 transaction에서
  성공 포인터를 전환한다. 오류·완전히 같은 원문의 반복·페이지 누락·0건은 이전 완결 집합을 바꾸지 않는다.
  원본 페이지와 이전에 저장된 자료는 삭제하지 않는다.
- 같은 복합 식별값의 서로 다른 원문은 임의의 첫 값·마지막 값으로 덮어쓰지 않는다. 공통 typed 값만
  공개하고 충돌 항목은 미제공으로 두며, 비고에 원천 불일치 안내를 표시한다. 원문 페이지의 모든 행을
  보존하고 인증 export의 해당 `raw`에 `source_records`·`conflicting_fields`를 담는다. 수신 원문 수와
  고유 시설 수·충돌 시설 수를 구분한다. 공개 조회가 원문 JSON을 읽지 않는 계약은 그대로다.
- 공개 목록·상세 API와 Map 등 소비자를 위한 인증된 service export를 제공한다. 공개 조회는 provider를
  호출하지 않고 필요한 열만 DB에서 읽는다. 페이지 사이 성공 세대가 바뀌면 cursor를 거절해 혼합을 막는다.
- 지도에는 별도 주차장 종류와 수량/요금 기준정보를 표시한다. 빠진 좌표는 격리하고 목록·상세는 유지한다.
- Map의 기존 월간 수집 주기를 따른다. API의 수집 전/미제공/오류를 빈 정상 완결 export로 꾸미지 않는다.
  Map의 후속 소비 경계는 Transport API이며 Map DB 직접 소비나 Map 패키지 import는 추가하지 않는다.

검증에는 기존 ID 갱신, 기관 코드 충돌 방지, 좌표 격리, 0값/소수 시간, 페이지 실패 rollback,
잘못된 cursor·세대 전환, 인증·범위 필터, 공개 조회의 원문 JSON 제외와 일정한 SQL 수를 포함한다.

실제 첫 조회에서 번호만의 충돌을 확인했고, 전체 18,994행을 읽기 전용으로 비교했다. SDK의
`insttCode`·`insttNm` alias가 빠진 문제는 해당 provider 라이브러리에서 수정한다. Transport에
원문 필드 우회 파서를 만들지 않는다. 이 SDK를 반영한 복합 식별값은 18,992개이며, 같은 시설의
두 자료가 요금·면수 등을 달리하는 두 그룹은 위의 보수적인 공개 규칙을 적용한다.
