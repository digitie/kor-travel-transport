# 철도 시간표·지도와 영구 지역 유가 통계

## 사용자 기능

- 철도 전용 지도는 24px 반경으로 묶고 줌 11부터 개별 역을 표시한다. 유가 지도 임계치는 유지한다.
- 마커는 노선 문자와 색상, 역 이름을 표시한다. 같은 번호 노선은 운영기관을 구분한다. 미등록 노선의 색상은 중립 토큰으로 표시한다.
- 코레일 공개 안내는 분류를 고르기 전 전체 페이지를 검산해 좌표를 연결한다. 공식 역 코드와 TAGO ID를 같은 코드로 간주하지 않는다.
- `/rail/timetable`에서 철도/도시철도, 운행일·행선지·전체/첫차·막차를 조회한다. 일반철도는 도시 선택을 먼저 강요하지 않고 모든 정상 조회된 도시의 역을 검색한다. 동명 역은 ID를 구분한다.
- 지도에서 선택한 일반철도 출발역은 TAGO 목록의 유일한 이름만 연결한다. 이름이 모호하거나 확인되지 않으면 이용자가 목록에서 선택한다. 수동 영구 매핑을 전제하지 않는다.
- 편의시설은 확인된 긍정 자료를 O로 표시한다. 미제공을 X로 변환하지 않는다. 새로고침은 SVG 아이콘을 사용한다.

## 수집·저장

KRIC의 기존 전체 48시간 대기를 제거한다. 시간별 제한 배치는 역·운행 기준별 `kric_timetable_attempts`를 먼저 commit하며 같은 대상을 24시간 안에 반복 호출하지 않는다. 정상 시간표는 개별 commit하고 실패해도 이전 저장본을 보존한다. 인증·할당량 실패는 원천 전체를 24시간 보호한다. 코드 파일·공휴일 확인도 하루 한 번 재사용한다. 최대 호출량·호출 간격·3시간 실행 상한을 유지하므로 전체 커버리지의 하루 갱신 달성 여부는 실제 미수집 수와 수집 처리량으로 확인해야 한다.

일반철도는 경로 응답을 24시간 저장 재사용한다. 매일 02:30의 `general_rail_timetable_collection_job`은 조회된 경로를 갱신한다. 지난 운행 날짜의 경로는 오늘로 옮겨 저장하되 날짜별 응답은 구분한다. 하루 최대 64개 경로를 오래된 순으로 처리한다. 모든 역 쌍을 무제한 수집하거나 미제공 역의 운행을 생성하지 않는다.

유가 통계는 별도 물리 서버 대신 현재 PostgreSQL의 전용 테이블을 사용한다. `fuel_region_summaries`는 `(source, generated_at, scope, region_key, product_code)` 기본키의 영구 수집별 요약이다. 성공한 Opinet 수집의 기존 통계 발행 경로에서 시도·시군구별 가격·주유소 수·분산·최저/최고 등을 함께 저장한다. 지도는 `fuel_statistics_states` 공개 세대와 조인한 작은 요약만 읽으며 원본 가격의 AVG/GROUP BY를 실행하지 않는다. 발행 실패 시 마지막 공개 세대가 유지된다.

지역 카드는 유종별 전체 지역 집계다. 지역 요약의 검색어는 지역명에 적용하며 주유소 일부 표본의 평균으로 바꾸지 않는다. 개별 주유소 검색·가격 필터는 상세 지도/목록에서 유지한다. 일별 요약은 하루 마지막 성공본을 교체하되 지난 날짜를 삭제하지 않는다. 화면의 7일 창과 영구 저장 수명을 분리한다. 기존 가격 point 세대의 제한 정리는 지역 영구 통계를 삭제하지 않는다.

`0037_fuel_regions_rail_daily`는 마지막 공개 가격 세대를 지역 요약으로 연결한다. 이를 새로운 수집 성공으로 기록하지 않는다. 영구 지역 행이 있으면 downgrade를 거부한다. 주차 원본 삭제·통계 backfill·백업·복원은 이 변경 범위에 포함하지 않는다.

## 검증 상태

구현·검증 중이다. 최종 운영 이미지·실제 시간표 커버리지·화면 캡처는 배포 수용 기록에서 정산한다. [유가 확장 검토](../reports/2026-11-01-fuel-analysis-feasibility.md)와 미제공 자료는 배포 성공과 구분한다.
