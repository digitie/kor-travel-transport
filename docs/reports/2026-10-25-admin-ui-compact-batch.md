# 2026-10-25 — 관리자 UI 첫 번째 작은 수정 묶음

## 범위

[조사 기반 설계](../design/2026-10-25-mobility-improvements.md)의 작은 UI 부분을 먼저 적용한다.
기존 관리자 메뉴·API·수집·Common 패키지 버전은 유지한다. PR은
[Transport #131](https://github.com/digitie/kor-travel-transport/pull/131)이다.

- 앱의 navy 팔레트와 공용 `--kt-*` 의미 토큰을 연결했다. 밝은/어두운 표면·선택·초점·상태·팝업의 색을 함께 맞춘다.
  다크 값은 기존 Weather navy 프로필을 따른다. 의미가 있는 주유소/교통 마커 색은 보존한다.
- 삽입 지도 바깥의 테두리를 제거하고 지도/목록의 같은 stage 한 곳에만 테두리를 둔다.
  `70dvh/64dvh`와 기존 캔버스 높이는 이번에 변경하지 않는다.
- 유가 지도의 큰 하단 통계 카드를 상부 요약으로 옮겼다. 유종을 선택하면 해당 서버 집계의 평균·최저·전체 주유소 수·시각을 표시한다.
  나머지 통계·최저가 주유소 주소 링크·집계 설명은 제목 옆 `i`로 연다. 목록 보기에서는 이 요약을 표시하지 않는다.
- 요약과 선택 상세는 같은 stage 안에서 내용 높이대로 쌓는다. 요약의 줄바꿈으로 상세가 덮이지 않고,
  짧은 상세가 남은 지도 높이만큼 불필요하게 커지지 않게 한다. 지도 자체의 크기는 줄이지 않는다.
- 육안 리뷰에서 초기화 불가 안내가 요약 뒤에 가려지는 회귀를 수정했다. 키 없음/WebGL 초기화 불가는
  기존 지도 위의 오류 영역으로 전달하고 목록에서는 표시하지 않는다. 지도 탭 복귀 때 재표시하고 fallback 언마운트 시 해제하며,
  기존 타일/network 오류 안내와 콜백 없는 `MapUnavailable` 소비자의 기본 표시를 유지한다.
- 주유소 상세의 주소/출처는 이름 있는 아이콘 팝업으로 모았다. 주소의 같은 지도 이동, 전화,
  유종별 가격·관측 시각·실패/갱신 지연 경고는 유지한다. 상세 header/footer의 출처 반복을 없앴다.
- 후속 점검에서 지도 아래의 지연 경고와 새 상부 가격이 분리되는 문제를 재현해 수정했다. `갱신 지연`과 가격 읽기 모델의
  마지막 갱신 시각을 요약 가격 바로 아래에 두고 선택 주유소 상세에도 표시한다. 판매 여부 설명은 제목 `i`로 옮긴다.
  유가 지도 아래의 중복 경고는 제거하고 목록 보기의 경고는 유지한다. 요약 재조회/실패에는 이전 가격과 경고를 함께 숨긴다.
- coarse 포인터에서는 유종 선택창도 44px로 키운다. 요약의 `i`는 재조회/실패에도 유지하고 팝업은 현재 조회 상태만 표시한다.
  갱신으로 실제 제거된 내부 활성 노드의 초점이 body로 소실된 경우에만 살아 있는 닫기 버튼으로 복귀한다.
  닫힌 팝업이나 사용자가 다른 입력으로 옮긴 초점은 건드리지 않는다.
- 가격이 있는 장소와 빈 통계가 함께 반환되는 정상 응답도 가격 갱신 상태를 표시한다. 통계 항목이 없다는 이유로
  지연 경고를 숨기지 않고, `통계 없음`과 기준 시각 결측을 구분한다. 이때도 판매 여부 설명은 같은 `i`에서 확인한다.
- 유가 통계는 실제 가격·최근 7일 범주 평균 추이·전체 범주 비교를 먼저 보여준다. 기존 차량 운영비 가정 계산은 하단에서 펼친다.

## 보존한 데이터 의미

지도 요약의 수치와 모집단은 기존 `include_fuel_statistics=true` 응답을 그대로 쓴다.
묶음 마커의 수나 클라이언트가 받은 일부 장소로 재계산하지 않는다. 유종 전환은 같은 서버 응답 안에서 선택하며,
재조회 중에는 이전 범위의 가격을 숨기고 조회 중/실패/빈 통계를 구분한다. 통계 반영 대기는 값 가까이에 남긴다.
최근 7일 그래프는 기존 지역·범주 평균이며 **개별 주유소의 가격 이력이 아니다**.

통계 항목 `generated_at`은 `publish_fuel_statistics`가 전달받은 `collected_at`을 공개 세대에 저장한 값이다.
즉석 집계 실행 시각이 아니므로 `통계 기준`으로 표시한다. `fuel_prices_last_refreshed_at`은 스키마가 정의한
가격 읽기 모델의 마지막 성공 갱신 시각이며 `가격 갱신`으로 표시한다. 둘을 개별 유종의 원천 관측 시각으로 대체하지 않는다.
시각이 비거나 유효하지 않으면 `확인되지 않음`으로 남기고 현재 시각을 만들지 않는다.

QA 서버는 후보의 `next.config.ts` 원본으로 `next dev --hostname 127.0.0.1 --port 12351`을 실행한다.
초기 `0.0.0.0` 실행의 dev resource origin 차단은 loopback 호스트 일치로 해소했다.
중간 QA 복제에만 두었던 `allowedDevOrigins` 보완은 최종 검증 전에 제거했으며 저장소에는 추가하지 않았다.
Firefox 실행은 기본 config의 live 타일 제한을 확장한 **QA 복제 전용** `playwright.compact.config.ts`를 사용했다.
기존 도시철도 fixture는 로컬 전용 로그인 설정과 loopback `TRANSPORT_UI_PUBLIC_ORIGINS`로 실행했다.
처음 Origin403으로 로그인 전 단계에서 멈춘 실행은 통과 증적에서 제외한다. 제품 인증 코드는 변경하지 않았다.
기존 375px fixture의 홈 메뉴 첫 열기는 Firefox/Chromium에서 각각 한 차례 실패했다. 이미 있던 클라이언트 조회 KPI 검증을
메뉴 클릭 앞에 두어 준비 순서를 보강했고 추가 P2를 포함한 32개 실행과 빈 통계 보완 후 36개 재실행에서 통과했다. 제품 메뉴 코드는 변경하지 않았다.
주입한 API fixture를 실제 타일·운영 데이터 정상의 증거로 세지 않는다.

스크린샷은 작업면의 `packages/kor-travel-transport-admin/frontend/test-results/compact-batch/`에 있으며,
`compact-fuel-{chromium|firefox}-{320|375|1440}-{light|dark}.png`와 JSON 결과를 보존했다. 생성 파일은 커밋하지 않는다.
초기화 오류 수정의 `compact-fuel-{chromium|firefox}-fallback-375.png`, 기존 fixture의 `metro-journey-{375|1440}.png`도 같은 경로에 보존했다.
지연 표시의 첫 화면은 `compact-fuel-{chromium|firefox}-stale-{375|1440}-{light|dark}.png`다.
빈 통계와 가격이 있는 장소가 함께 온 경우는 `compact-fuel-{chromium|firefox}-empty-stale-{375|1440}-{light|dark}.png`다.
coarse 선택창은 `compact-fuel-{chromium|firefox}-touch-{320|375}.png`다. 두 브라우저와 두 폭 모두 실제 높이가
30px이던 것을 재현한 뒤 44px를 확인했고 제목/선택창/안내 버튼이 겹치지 않으며 가로 넘침이 없는 것을 단언했다.
운영 이미지 빌드·배포는 사용자 지시에 따라 실행하지 않았다. Docker 2차 검증·CI·독립 리뷰와 최종 SHA는
[PR Checks](https://github.com/digitie/kor-travel-transport/pull/131/checks) 및 PR의 최종 검토 기록을 정본으로 삼는다.

지연 경고 보완 전 `0d8024e`의 같은 fixture에서 375×812의 가격은 y539~560, 경고는 y1069.4~1111.4로 509px 떨어졌고,
1440×900의 가격은 y368.5~389.5, 경고는 y960.5~981.5로 571px 떨어져 모두 경고가 첫 화면 밖이었다.
보완 뒤 경고는 각각 y564~582, y393.5~411.5이며 두 폭 모두 가격 하단에서 4px 뒤에 첫 화면 안으로 들어온다.
이 측정은 키 없는 QA fallback을 포함한다. 기존 base의 하단 경고 코드를 새로 내린 문제가 아니라, 새 요약을 위로 옮기면서
가격 상태를 함께 옮기지 않은 문제였다. 지도 전체 가용 높이의 수용과는 구분한다.

독립 게이트는 James/Popper다. 초기 후보 `0d8024e`의 Popper 전체 리뷰는 같은 지연 경고 분리를 P1로 지적했고
다른 지적은 없었다. James는 같은 지연 문제 외 coarse 선택창 30px와 재조회 시 안내 팝업의 초점 소실을 P2로 지적했다.
팝업 안의 링크에 초점을 두고 pending으로 바꿀 때 안내가 제거되는 단위 실패를 먼저 재현한 뒤 수정했다.
이 문서는 P1/P2의 재현·수정·로컬 재검증을 기록하며 최종 후보의 독립 재리뷰를 PASS로 세지 않는다.
최종 SHA·CI·James/Popper 재리뷰 판정은 위 PR 정본을 따른다.

후속 후보 `606f582`의 James 사전 차이 리뷰에서 `fuel_statistics: []`, `fuel_prices_stale: true`와 가격이 있는
`items`가 함께 오는 정상 응답은 요약의 지연 경고가 빠지는 경로를 찾았다. 통계 상태가 아직 공개되지 않았거나
선택 원천이 OPINET이 아닌 경우의 빈 통계는 장소/가격 부재와 같지 않다. 유효한 가격 갱신 시각과 빈 시각 각각의
단위 실패 2건을 먼저 재현한 뒤, 정상 응답의 가격 상태를 선택 통계의 존재 조건에서 분리했다.
통계 없음 문구, 조회 중/실패의 이전 가격·경고 숨김, 빈 시각의 `확인되지 않음`은 유지한다.
브라우저 fixture는 가격이 있는 좌표 장소의 건수·목록/상세 가격과 빈 통계·지연 경고의 동시 표시를 검증한다.
375/1440px 두 브라우저의 밝은/어두운 첫 화면에서 지연 시각과 통계 없음이 함께 보이고, 목록 경고·선택 상세 가격과
빈 시각을 확인했다. 타입/lint·35파일 263개와 기존 32개를 포함한 브라우저 36개를 다시 통과했다.
키 없는 fallback이므로 실제 지도 위 가격 마커나 운영 타일의 표시 성공을 증명하는 것은 아니다.
`606f582`에 시작된 CI와 최종 후보의 독립 재리뷰는 여기서 최종 통과로 기록하지 않는다.
