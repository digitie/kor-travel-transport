# 유가 분석 확장 검토

## 2026-11-02 공식 필드·공표 원천 재확인

- [오피넷 상세정보 계약](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=1)은 KPETRO_YN을 한국석유관리원 품질인증프로그램 협약 여부로 명시한다. 로컬 SDK는 이를 is_kpetro로 반환한다. 관측 시각·원천을 붙인 필터는 구현 후보이며 검사 성적이나 무위험 보증을 뜻하지 않는다.
- [오피넷 불법행위 공표](https://www.opinet.co.kr/dlarSelect.do)는 지자체 게시 자료이며 [공표 안내](https://www.opinet.co.kr/user/cufaq/cufaqDetail.do?BORD_SN=38&TAB_CODE=USER)는 공표 기간과 대상이 제한됨을 설명한다. 현재 게시되지 않은 업체를 과거 위반 이력이 전혀 없는 업체로 분류하지 않는다. 공표 원문·처분 시점·기관·오피넷 ID의 확정 연결을 확보한 뒤 이력 오버레이를 구현한다. 대표자 등 불필요한 개인 정보는 분석에 보관하지 않는다.
- [공식 상세 API 반환 항목](https://www.opinet.co.kr/user/custapi/openApiInfoDtl.do?apiId=1)에는 판매량·재고·입고 로트가 없다. 현재 확보한 가격·주소·시설만으로 실제 탱크 회전율·수분·연료 신선도를 산출할 근거가 없다. 화물/택시 동선 근접성은 접근성 정보로만 표시할 수 있고 품질 점수로 치환하지 않는다. 다른 계약으로 직접 관측 자료를 확보할 수 없다는 뜻은 아니다.

아래 최초 검토와 구분해 공식 계약을 재확인했다. 이 검토는 신규 품질 점수·이력 수집기의 운영 배포를 뜻하지 않는다.

## 결론

먼저 실제 가격 차이·공표 여부·인증 여부를 제공한다. 이를 합산한 ‘무위험 점수’나 검증되지 않은 연료 품질·동절기 교체 확률은 만들지 않는다.
이번 구현은 지역 통계의 수집별 영구 저장이며, 아래 지표를 이미 운영 제공한다는 뜻은 아니다.

| 요청 | 현재 확보 상태와 구현 판단 |
| --- | --- |
| 불법·유사석유 적발 이력 | 기존 `fuel_stations.is_illegal`은 현재 수집된 표시다. 과거 위반 전체·처분 종류·기간을 뜻하지 않는다. 별도의 처분 원문·공표 기간·관할기관·사업자 식별자를 저장한 뒤 이력 오버레이를 권장한다. 조회되지 않음을 ‘위반 이력 없음’으로 표시하지 않는다. |
| 품질인증·안심주유소 | 기존 SDK와 DB의 `is_kpetro`를 활용할 수 있다. 인증 프로그램과 확인일을 함께 표시하고 최신 공식 협약 현황과 대조한다. 인증 여부를 무결점 보증으로 바꾸지 않는다. |
| 회전율·신선도 | 실제 판매량·재고·입고 이력이 없다. 화물 동선·택시 차고지와 가깝다는 사실로 회전율이나 수분·변질 위험을 계산할 수 없다. 실제 방문 자료를 확보하더라도 ‘방문 인기도’와 연료 품질을 구분한다. |
| 동절기 경유 전환 확률 | 입고 로트의 시험 성적·탱크 재고·혼합·판매량이 필요하다. 현재 자료로 확률을 산출하지 않는다. 제안된 CFPP −18℃를 전 지역·기간·제품에 동일 적용하는 기준으로 확정하지 않았다. 실제 제품/기간의 공식 품질기준과 시험 성적 확인이 선행된다. |
| 알뜰·무폴 실제 공급 정유사, 직영·자영 | 상표와 공급 로트·사업 운영 형태는 다른 정보다. 기존 상표 코드로 실제 공급사를 추정하지 않는다. 계약·납품·공식 운영 주체 자료의 접근성과 갱신 계약을 별도로 확인해야 한다. |
| 탱크 노후도·클리닝 | 개업 연도는 탱크 설치·교체·청소일이 아니다. 설비 이력 원문이 없으므로 수치 위험 지표를 보류한다. |
| 일반유–고급유 스프레드 | 가장 먼저 구현 가능한 가격 지표다. 같은 주유소의 유효한 두 가격을 같은 수집 세대에서 짝지어 계산한다. 150원/L 이하 필터와 지역의 짝지어진 표본 수·기준시각을 함께 제공한다. 서로 다른 판매소 집단의 평균 두 개를 단순 차감하지 않는다. |
| 경유+요소수 | 요소수 가격은 공식 API 제공 범위에 있다. 다만 벌크 주입기 여부·포장/벌크 구분·단위는 실제 응답 계약을 더 확인해야 한다. 경유와 요소수 소비량이 달라 두 리터당 가격을 그대로 합하지 않는다. 주행거리·소비 가정별 비용으로 분리 계산한다. |
| 다음 주 소매가 방향·변동폭 | 국제 제품가격·환율·세금·공급가격의 시점별 이력이 필요하다. 시차를 1~2주로 고정하지 않고 과거 구간에서 검증한다. 미래 자료 유입을 막은 순차 평가·확률 보정·예측 구간·미예측 상태를 갖추기 전 인상/인하 확률 알림을 내지 않는다. |
| 가격 반영 탄력성·로켓–깃털 | 새 영구 지역 이력은 기반이 된다. 주유소별 장기간 가격·영업/상표 변경·국제 제품가격·환율을 추가 확보해야 한다. 상승/하락 반응의 관측 차이와 추정 불확실성을 표시하고 사업자의 의도를 단정하는 배지를 붙이지 않는다. |

## 확인한 출처와 범위

- [오피넷 공식 API 안내](https://www.opinet.co.kr/user/custapi/custApiInfo.do): 지역·주유소 판매가격과 요소수 가격 제공 범위를 확인했다. 유료/제휴 조건과 상세 필드 계약은 기능별로 확인한다.
- [한국석유공사 공공데이터 안내](https://www.knoc.co.kr/images/202310251016.pdf): 불법행위 공표사항과 국제·국내 유가 자료 안내를 확인했다. 전체 과거 이력 API의 실제 수용을 완료했다는 뜻은 아니다.
- [한국석유관리원 품질인증 운영 매뉴얼](https://www.kpetro.or.kr/direct_download.do?file_nm=2022_Manual.pdf&path=%2Fupload%2Fstatic&rfile_nm=%EC%84%9D%EC%9C%A0%ED%92%88%EC%A7%88%EC%9D%B8%EC%A6%9D%ED%94%84%EB%A1%9C%EA%B7%B8%EB%9E%A8+%EC%9A%B4%EC%98%81+%EB%A7%A4%EB%89%B4%EC%96%BC.pdf): 인증 프로그램 자료다. 최신 협약 목록 URL은 조회 중 redirect loop로 수용하지 못했다.
- 로컬 `python-opinet-api`의 `StationDetail.is_kpetro`와 Transport의 `is_illegal`, `is_kpetro`, 유종별 가격 저장 필드를 확인했다. 현재 필드의 소비와 신규 이력 수집은 별도 과제다.

우선순위는 스프레드 → 출처·시각이 붙은 인증/공표 표시 → 요소수 계약 확인 → 장기 가격 반응 분석이다. 나머지는 필요한 직접 관측을 확보한 뒤 재평가한다.
