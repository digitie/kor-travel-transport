## 구조와 책임

교통·유가·고속도로·일반철도·도시철도·고속버스·시외버스·공항 지도·배편의 9개 경로를
동일한 `MapWorkspace → MapFilterPanel → MapTabs/MapViewTabs → MapStage` 구조로 연결했다.
공용 `summary`와 `detail` 슬롯, 상세의 고정 제목·닫기와 내부 본문 스크롤을 소비한다.
외곽·필터/상세 접기·안전 영역 정책은 Common이 소유한다. 앱은 상위 shell의 유한한 남은
높이와 도메인 필터·오류·요약·선택 상세를 제공하며 공용 측정 hook이나 SDK resize를 복제하지 않는다.

지도 전용 shell만 간격·제목을 압축하고 부모 flex/grid에 `min-height:0`을 연결했다.
지도마다 반복되던 `70/64dvh`, `28/22rem` 최소 높이를 제거했다. 지도 canvas와 초기화
실패 여부에 관계없이 같은 stage를 유지하며, 키가 없을 때 배편 지도가 2px이 되던 문제도
동일한 부모 계약으로 다룬다. 운영 홈/표 화면과 공항 기본 화면의 문서 흐름은 유지한다.

모바일/짧은 화면의 필터는 접힌 상태로 진입하고 적용 조건만 짧게 요약한다. 검색 후보는
지도 앞에 길게 쌓지 않고 목록 탭으로 옮겼다. 시간표·운항편 비교는 첫 작업면 뒤의 별도
문서 흐름을 유지한다. 공항은 주차·이후 항공편·패턴을 기본으로 두고 명시적 공항 지도
버튼을 눌렀을 때만 지도 작업면과 선택 상세로 들어간다. 자동 공항 선택은 상세 열기와 구분한다.

기존 삽입 지도는 외부 `places`일 때 자체 장소 API를 호출하지 않는다. 일반 장소 선택이
없는 고속도로 `detailKey`, 선택 반복의 `focusRevision`, Escape/닫기 뒤 열었던 컨트롤 복귀를
보존한다. 목록→지도 재마운트에서는 실제 지도 중심/줌을 상태에 보관해 초기 카메라로 돌아가지 않게 했다.
전환 중 이전 Panel이 잠시 유지되는 경계에서는 map/list 상세 ref를 분리한다. 이전 상세 언마운트가
새 활성 ref를 비우지 않으며, 닫은 뒤 opener가 연결돼 있어도 숨겨지거나 inert이면 보이는 지도/필터로 복귀한다.

가로/문자 확대에서 기본 작업면의 물리적인 높이 제한을 확인해 공용 opt-in `expandable`을 사용한다.
`지도 크게 보기`는 같은 DOM/엔진/조회 조건을 유지하고 앱의 rail/PageHeader만 접는다. shell grid의
행·열을 모두 한 칸으로 바꾼다. 자식이 처리한 Escape는 상세/팝업만 닫고, 미처리 Escape는 작업면을
원래 상태로 돌린다. 시간표/비교의 followup은 숨기지 않고 아래 sibling으로 유지한다. 초기 확장에서
followup을 숨기면 링크의 hash만 바뀌고 목적지 사각형은 없던 실패를 재현한 뒤 이 한 조건을 제거했다.
일반/도시철도·버스·배편의 native anchor 왕복과 지도 높이 보존을 확인하고 목적지에 지도 복귀 링크를 뒀다.

유가 기본 요약은 유종·평균/최저·갱신 지연·가격 갱신 시각을 우선한다. 전체 집계 모집단,
건수·통계 세대의 원천 수집 기준은 `i` 안에 보존한다. 가격 읽기 모델의 마지막 성공 갱신과
개별 가격 관측 시각을 혼동하지 않는다. 빈 통계의 지연 경고, 조회 중/실패 시 이전 가격·경고
숨김, 팝업 갱신 초점, 44px 터치 컨트롤을 유지한다.

글자 배율을 유지한 채 오류는 `지도 키 없음 · 목록 보기`처럼 행동에 필요한 짧은 문구로 만들고,
범위 가격 단위는 헤더의 `원/L` 한 번으로 줄였다. 가격 시각은 `26.10.25 10:00 KST`로 표시하고
원본 ISO 시각을 `<time datetime>`에 보존한다. 없는/잘못된 시각은 `시각 미확인`이며 현재 시각으로 채우지 않는다.
선택 주유소 상세가 열리면 범위 요약은 명시적인 `현재 지도 범위` 버튼으로 접는다. 닫으면 원래 범위를
복원하고 사용자가 직접 펼친 의도는 지도·목록 왕복에도 유지한다. 접힌 범위의 가격은 보이지 않으며,
선택 주유소의 지연/시각·가격은 상세 본문에서 읽는다. 주유소는 불필요한 본문 접기 버튼을 쓰지 않고
공용 닫기 44px를 유지해 제목과 본문 공간을 확보한다. 다른 도메인의 상세 접기 계약은 유지한다.

Chromium에서 출처 팝업을 연 채 PC→모바일로 바꾸면 anchor가 숨겨져도 portal 목록이 남는 실패를
재현했다(Firefox는 같은 조건에서 정상 닫힘). 앱 `FilterCombobox`는 열려 있을 때 실제 anchor의
레이아웃 소실을 관찰해 제어 `open`을 닫는다. 공용 breakpoint나 viewport 높이를 복제하지 않는다.
이는 [shadcn 다중 Combobox 구성](https://ui.shadcn.com/docs/components/base/combobox)과
[Base UI의 제어 open/anchor 상태 계약](https://base-ui.com/react/components/combobox)을 따른다.

## 로컬 검증과 남은 게이트

첫 실행 후보 `78efe539a4e6ad94c2da50c18ca67d706563d315`의 전체 작업면 fixture는 112개 중
110개 통과/고속도로 상세 초점 2개 실패였다. 목록 선택 뒤 지도 상세는 보이지만 focusin은 목록 버튼까지만
기록되고 활성 노드가 BODY로 빠졌다. map/list가 같은 ref를 쓰고 이전 Panel의 늦은 언마운트가 활성 ref를
비우는 원인을 새 단위 1개 실패로 재현했다. ref 분리 뒤 고속도로 상세 자동 초점→Escape와
기존 도시철도의 주소→지도→자동 초점→Escape/목록 opener 복귀를 양 브라우저에서 확인했다.

추가로 PC 공항 select로 상세를 연 뒤 375px로 줄여 필터를 접으면, 연결된 숨은 select로 초점을 돌려
복귀가 실패하는 실제 경로를 브라우저 1개 실패로 재현했다. 가시성/inert 검사를 추가한 뒤 같은 단언으로
양 브라우저 통과했다. 신규 공항 fixture의 첫 두 실패는 중복 `/transport/` 경로를 누락한 route 패턴으로
두 번째 공항이 주입되지 않은 선택 timeout이며 제품 실패와 구분해 보존했다.

실제 API/타일을 쓰는 별도 `78efe` 검증에서 모바일 좌표행이 추가되면 stage y259였고 SDK zoom은
