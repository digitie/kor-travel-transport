# 공항 주차 분석용 항공편의 공동운항 조회 복구

## 문제와 책임 경계

공항 주차장의 하루 흐름·출도착 조회가 김포 정상 공동운항을 중복 오류로 거부했다.
원인은 Transport UI나 저장 캐시가 아니라 고정한 `python-krairport-api`의 GW 전체 조회에서
`fid` 하나만으로 중복을 판정하던 로직이었다. 제공기관의 같은 `fid`를 공유하는 서로 다른
편명을 SDK가 먼저 거부해 기존 `/v1/flights/status`가 `upstream_error`를 반환했다.

필드 의미와 페이지 검증은 [ADR-004](../adr/004-krairport-provider-library.md)에 따라
형제 SDK에서 수정했다. Transport에는 provider 우회·파서·새 DTO·API를 추가하지 않는다.
`backend/pyproject.toml`과 `backend/uv.lock`은 SDK만
`6c9aa9ae2ad77cbef3fb538d23f5da1f362e0482`에서
`0a7648450c62027fb95146a2442c3f925c80d6aa`로 갱신한다.
[SDK PR12](https://github.com/digitie/python-krairport-api/pull/12)가 해당 SHA를 main에
포함한 뒤 소비자 PR을 머지한다. 다른 provider·전이 의존성 버전은 바꾸지 않는다.

## 공식 명세와 실제 응답

[공식 15158625 Swagger](https://www.data.go.kr/data/15158625/openapi.do)의 편명별 유일
코드 설명과 달리, 김포 2026-10-25 출발 첫 페이지 100행은 공동운항 21그룹 47행에서
`fid`를 공유했다. 완전 중복은 없었고 모두 명시적 공동운항·같은 대표 편명·날짜·방향·
노선·예정시각을 가졌다. `fgenTime`만 2초 차이인 정상 그룹도 있었다.

SDK는 방향별 `(fid, flight_id)`로 식별한다. 같은 `fid`의 다른 편명에는 명시적 공동운항,
같은 비어 있지 않은 대표 편명·출도착 공항 코드·예정시각과 주어진 원본 날짜/방향의 일치를
요구한다. 개별 편명·대표 편명·원본·KST는 보존하며, 중복 편명/예정시각 변경 재등장,
겹친 페이지·메타데이터 변경·잘림·중간 빈 페이지·예산 소진 검증은 유지한다.
`fid`가 없을 때의 기존 대체 식별자도 유지한다. 생성 시각은 일치 조건에서 제외한다.

## 재현과 수용

- SDK 공개 100행 XML 재생에서 기존 pin의 중복 오류를 먼저 재현했다.
  최종 SDK는 오프라인 299개·커버리지 92.55%, compileall·Ruff·mypy 24파일과 SKILL 검증을 통과했다.
- 소비자 새 회귀는 실제 공개 7행의 SDK XML 파싱→기존 `FlightStatusService`→기존 API를
  통과시킨다. 이전 SDK로 정상 3사례가 실패했고 수정 pin으로 기존 항공편 회귀까지 18개를 통과했다.
  모순된 공동운항/실제 중복 3사례는 계속 `upstream_error`이며 빈 성공으로 숨기지 않는다.
- 기본 테스트와 분리한 실제 SDK 수용은 김포 2026-10-25 한 공항/하루에 한정했다.
  재시도 0·redirect 0·1 RPS·두 방향 합산 상한 20페이지 중 GET 6회로 출발 235편·도착 238편,
  총 473편을 읽었다. 공유 `fid`는 97그룹 217행이며 개별 편명이 보존됐다.
- 실제 473행을 추가 외부 호출 없이 같은 SDK의 XML 6페이지로 재생해 기존 API까지 검증했다.
  API는 기존 공동운항 마커 묶음 계약대로 353마커와 편명 구성원 473개를 제공했다.
  방향·예정 UTC 시각·개별 편명의 다중집합이 원본 473편과 일치했고 같은 API 재조회는
  추가 SDK 페이지 없이 캐시를 사용했다. 공개 원본의 API 재생은 실제 외부 GET 6회의 결과와 구분한다.
- `backend/tests/fixtures/kac_codeshare_public_20261025.json`은 실제 응답에서 선택한 공개 7행이다.
  부분 집합 재생용 총건수를 사용하므로 하루 전체 완결성 증거로 세지 않는다.

## 미완료와 운영 경계

위 수용은 해당 공항/날짜의 제공 범위이며 전국 완전성·동일 시점 스냅샷을 보장하지 않는다.
인증키·인증 URL·헤더는 argv·stdout·fixture·증빙에 기록하지 않았다.
운영 DB·원본 수집 job·Dagster 스케줄·이미지 빌드·배포는 변경하지 않았다.
