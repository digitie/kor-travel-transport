## 현재 판정

**제품 보완·검증 진행 중이며 운영 배포는 미완이다.** 사용자는 전체 UI를 수정한 새 릴리스를
선택했다. 이전 `3f5160a0`의 일부 미완을 유예하는 경로는 사용하지 않는다.
Weather는 앞서 완료한 상태를 유지한다.

## 이전 실패 보존

이전 후보의 실제 Firefox 검증은 115항목 중104통과·11실패였다. 타일330개의 HTTP200과
서울→부산 현재 날짜75편의 PC/모바일 조회는 통과했지만 전체 UI 수용은 실패했다.

## 문서 정합성 검토

관련 코드·설정·현재/과거 상태와 계약 문장을 두 차례 대조하고, 상대 링크와 OpenAPI 입력·DTO를
검산했다. 이후 문서만의 독립 적대적 리뷰에서 KAC/IIAC 파싱 경계 P1과 검증 소스 계보·
ICN 시각 대체 설명 P2를 수정했다. 최종 독립 문서 리뷰는 미해소 지적0이다.
문서 검토를 제품 전체의 두 적대적 리뷰나 운영 완료로 해석하지 않는다.

## 실제 데이터 조사

- 기존 운영 키를 RAM에서만 사용한 GMP SDK 요청1회가 실제4행을 반환했다. 키·URL query·원응답은
  로그에 내보내지 않았으며 수집 플래그·DB 쓰기·추가 provider 요청은0이었다.
- 별도 읽기 전용 집계에서 저장 요금40행은 모두 ICN이었다. 이 중36행은 주차장 연결,
  4행은 이름 있는 공통 행이었고 GMP/PUS/CJU는0행이었다. 따라서 수집 OFF 안내만 표시하는 것으로
  실제 주차요금 계산의 운영 수용을 끝낼 수 없다.
- 기존 공개 bootstrap의 실제 ICN 주차장 이름·terminal/category를 대조한다. 장기/예약 주차장의
  문자열 prefix가 다르다는 이유로 특정 요금을 공통 규칙으로 승격하지 않는다.
