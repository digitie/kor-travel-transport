# 주변 유가 플러그인 VWorld 지도 수정 (2026-11-28)

## 원인과 변경

PR305의 MCP 리소스에는 지도가 있었으나 기존 개인 Site의 웹 루트는 목록 전용이었다. 웹 루트를 공식 MCP Apps AppBridge에 연결하고 같은 위젯을 사용한다. 사용자의 추가 지시대로 지도 엔진은 fuel과 동일한 `maplibre-vworld-react`(web1.0.4/core1.0.1, MapLibre GL6.17.0)로 통일했다.

검색 시 지도·반경 원·가격/개수 마커가 기본 표시된다. 명시적 목록 선택은 유지한다. 선택 마커는 위로 표시하고 겹친 마커의 최대 줌 목록은 클릭/키보드에서 즉시 닫히지 않는다. 위치 권한은 사용자가 요청할 때만 사용한다.

## 키·인증 경계

키 없는 정적 HTML을 빌드한다. Native API는 기존 설정의 VWorld 키만 HTML-safe JSON으로 주입한다. Site는 서버 빌드 산출물 또는 런타임 설정에서 같은 지도 키를 주입한다. 키 값은 소스·Git·출력에 남기지 않는다. MapLibre ESM worker의 shared 의존성을 단일 Blob worker로 묶는다. CSP는 VWorld와 Blob으로 제한한다.

Site의 위젯 문서는 인증을 요구한다. 도구 중계는 동일 출처·인증·두 읽기 도구·실제 누적4096바이트 한도를 적용한다. 서비스 토큰은 서버 전용이다. 기존 개인 공개 범위와 MCP 데이터 도구의 다섯 유종 계약을 유지한다.

## 실제 검증

- 로컬 Ubuntu-26.04 WSL2 ext4와 로컬 Docker에서 수행했다. UI 단위23개·집중 PostgreSQL18 시험19개가 WSL/Docker에서 각각 통과했다. 중복 결과는 합산하지 않는다.
- 엄격 sandbox 브라우저13개가 통과했다. 첫 worker/CORS 실패와 수정 이력은 작업 원장에 보존한다. 이후 비동기 onError 종료 가드만 추가하고 최종 타입/빌드와 실제 화면을 재확인했다.
- 최종 단일 HTML은2639711바이트, SHA256 `9de561f9302f39b9cd44cce78e0f8e3fa5e713e0170b21721d79a3fade75662f`이다. ARM64용 UI Docker export와 바이트가 같다. API Python/SDK 이미지는 빌드·배포하지 않았다.
- Site 시험54개·타입 검사·Worker 빌드가 통과했다. 실제 in-app browser PC·375px에서 공식 브리지, 기본 지도, 실제 VWorld 배경지도·반경 원·가격 그룹과 가로 넘침0을 확인했다. 가격/주유소 자료는 서울시청 주변 fixture이며 사용자 위치나 운영 가격 수용이 아니다.
- 기존 두 독립 리뷰의 팝업 이벤트 전파·선택 마커 순서·스트림 바이트 제한 지적을 수정하고 재확인했다. P0/P1 미해결 없음.

## 배포 범위와 한계

Site 게시와 Transport Native 소스 CI/머지/이미지 적용은 별개다. 이번 작업은 기존 개인 Site만 게시하며 Transport 운영 API·fuel web 이미지·DB·수집·환경을 변경하지 않는다. Native 리소스는 후속 API 이미지 적용이 필요하다. 실제 ChatGPT inline 호스트의 추가 CSP 제한과 Android/iOS 마이현대 실제 수신은 별도 검증 대상이다. 웹 루트의 실제 VWorld 표시는 로컬 최종 Worker에서 확인했다. 게시 결과는 Site 원장으로 별도 정산한다.

## 대화 위젯 진입점과 화면 간소화

설치된 플러그인의 기존 현재 위치 도구가 웹 링크만 반환하는 것을 도구 호출로 확인했다. 개인 Site의 MCP 도구 설명에 대화 내 위젯 호출 조건을 안내하고, 그 도구와 좌표 기반 렌더 도구에 동일한 위젯 리소스를 연결했다. 지도 안에서 실행하는 재조회는 같은 브리지로 응답을 받아 화면을 갱신한다. 현재 위치 요청은 좌표 없이 시작하며, 사용자가 요청한 반경·유종은 위치 동의 이후의 조회로 전달한다.

공통 위젯은 위치 동의 전에는 검색 버튼을 우선 표시한다. 검색 후 지도·최저가·평균가·주유소 목록을 표시한다. 반경 변경·좌표 입력·정렬, 목록 검색·지역 비교, 주유소 공유는 해당 항목을 펼쳐 이용한다. 응답에 한 유종만 있으면 유종 선택을 숨긴다.

## 주유소·길찾기 우선 배치

ChatGPT 앱에서 도구 목록을 갱신하고 새 대화로 수지구청 반경 10km의 실제 유가를 조회했다. 지도 도구 호출은 성공했지만 가격 요약만 표시됐고, 실제 지도는 나타나지 않았다.

지도 라이브러리와 가격 데이터는 유지하면서 단일 MCP HTML을 약 2.64MB에서 0.99MB로 줄였다. 기존 인라인 모듈을 브라우저에서 복원하며 외부 코드 주소를 추가하지 않는다. 위젯 템플릿에는 인라인 표시를 명시하고 리소스 로드 여부는 좌표나 인증값 없이 기록한다.

지도와 주유소 목록 위주로 표시한다. 주유소 선택 시 상세 상단에서 길찾기를 열고, 반경 통계는 목록 아래 한 줄로 표시한다. MCP 도구의 텍스트도 주유소 위치와 가격, 길찾기부터 안내한다.
