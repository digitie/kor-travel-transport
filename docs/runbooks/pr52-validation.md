# PR #52 지도 다중 필터 검증

## 변경 범위

- 지도 데이터 출처/유종을 shadcn/Base UI 다중 combobox로 전환한다.
- 우측 중복 장소 선택을 제거하고 상세 닫기 시 장소 검색으로 포커스를 돌린다.
- `/v1/transport/features/places`에 `sources`와 `product_codes`를 추가한다.
  같은 조건 안은 OR, 출처와 유종 사이는 AND다. 유종 조건은 주유소에만 적용한다.
  상세 가격 배열은 모든 유종을 유지한다. 기존 `source`, `product_code`도 지원한다.
- 쉼표 구분 값은 출처 최대 10개/유종 최대 5개다. 빈 값, 과다 선택, 해당 단일·다중
  조건의 동시 지정은 422로 거절한다. OpenAPI 문서에 계약을 반영했다.
- DB 스키마·수집 주기·provider·인증·포트·기존 parking-radar 구현은 변경하지 않는다.
  나머지 지도/검색 개선과 유가 분산 수집은 이 PR 완료 범위가 아니다.

## 후보와 검증

보완으로 최종 후보를 갱신하므로 이 이미지들을 그대로 운영에 배포하지 않는다.

UI 행렬은 모의 응답 기반 경계 검증과 기존 운영 저장 DB 읽기를 혼합한다. 모든 검사가
외부 제공자를 호출한 것은 아니며, 로컬 통과는 운영 후보 배포 후 live 통과와 구분한다.
로컬 임시 인증서 검증 예외는 운영 검증에 사용하지 않는다.

전체 WSL 최초 실행은 355개 통과·13개 실패·6개 환경별 제외였다. 실패 13개는 Git에
없는 빈 `backend/scripts` 디렉터리가 배포 guard 테스트의 경로 탐색을 가린 문제다.
소스·기준을 바꾸지 않고 동일 후보의 Git archive에서 해당 13개를 다시 실행해 모두
통과했다. Docker 전체도 355개 통과·같은 경로 문제 13개 실패·6개 환경별 제외였으며
깨끗한 사본의 13개를 별도 재실행해 모두 통과했다. 이를 최초 전체 실행이 무결하게
통과했다고 표현하지 않는다.

## 실패 보존과 예비 리뷰

- Escape로 선택 칩이 전부 사라지는 Base UI 기본 동작을 재현하고 목록/검색어 닫기만
  허용했다. 작은 화면 popup은 가용 높이 안에서 스크롤하도록 보완했다.
- 검색 debounce 중 이전 장소를 눌렀을 때 새 빈 검색에 상세가 남는 실패를 재현하고,
  확정 검색어 변경 시 선택을 해제했다. 가상시계 시험은 브라우저 시계를 기준으로 한다.
- 칩 삭제 영역 28px를 터치 시험으로 재현하고 44px로 수정했다. 320~1440px, 키보드,
  OR 전용 장소, 오류 후 이전 결과 제거, 출처 10개 제한/해제 회귀를 추가했다.
- 최초 UI 확장 검사의 대시보드 실패 3개는 로컬 upstream 설정 누락이었다. 설정을
  고친 뒤 전체 관련 395개가 통과했다. timeout/검사 기준을 낮추지 않았다.
- 최초 `112d9de` CI는 기존 `test_waiters_share_total_request_deadline`의 `calls == 1`
  가정으로 1개 실패했다. 예비 Popper 독립 재현 300회 중 2회는 순차 재계산 2번이지만
  최대 동시 handler는 1, 모든 결과는 504, lock/슬롯 반환도 정상이었다. 요청별로
  deadline이 다르므로 실패 owner 뒤에 예산이 남은 waiter가 재시도할 수 있다.
  최신 후보 CI 두 실행은 통과했다. 이 PR에서 통계 로직/검사 기준은 바꾸지 않고,
  테스트의 동시성 불변식과 만료 예산의 handler 진입 경계 보강을 별도 P2로 남긴다.

## 정식 독립 리뷰와 보완

- James(에이전트 표시명 Popper): P0/P1 없음, 낮은 화면의 마지막 옵션 부분 잘림과
  긴 출처명 잘림 P2 두 건. `hover`나 `scrollIntoViewIfNeeded`의 자동 스크롤을 쓰지
  않고 휠만 움직여 마지막 44px 항목 중 23.75px만 보이는 실패를 재현했다. 비어 있는
  안내 요소의 padding을 숨기고 옵션 이름에 줄바꿈을 적용했다. 두 회귀를 추가했다.
- Popper(에이전트 표시명 Schrodinger): API P0/P1 없음. 80자 출처 10개의 CSV 길이
  809자가 800 제한으로 거절되는 P2를 재현해 809로 맞췄다. 길이 경계 회귀를 추가했다.
- 운영 보조 스크립트 P1: rollback 실패 뒤 daemon 재개를 모의 함수로 재현했다.
  이전 API/code-server 이미지·health·소스 복구를 확인해야 release 기록과 daemon을
  재개하도록 바꿨다. 실패 시 중지 유지/정상 복구 시 재개 두 모의 검사가 통과했다.
  소스 되돌리기는 검증된 하위 경로만 정확 복원하여 후보가 추가한 파일도 제거한다.
- stage 소스와 이미지의 일치 검증 P2도 배포 전 manifest 검증으로 보완한다.
  보완 후 CI·두 리뷰어 재확인·운영 검증은 아직 미완료다.
