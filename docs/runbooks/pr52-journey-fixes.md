  시간표에는 코드를 표시하며 API `port_name`은 기준정보에서 조인해 반환한다.
  링크의 알 수 없는 항구 코드를 이름으로 대체하지 않고 오류를 표시한다.

## 배포 전 필수 조건

1. 현재 dirty 후보는 미배포다. 기존 API `91262cc`, UI `1558a01` 운영 검증은 신규 수정의
   검증을 대체하지 않는다. PR #52 Draft와 머지 보류를 유지한다.
2. 최신 전체 WSL·Docker·PostgreSQL·CI, 최종 후보에 대한 James/Popper 독립 리뷰가 필요하다.
3. `0016` 적용 전 현재 운영 원본과 DB 백업, 스키마 호환 되돌림 이미지를 준비한다.
   기존 API는 정확한 `ALEMBIC_HEAD=0015`를 요구하므로 단순 이전 이미지 교체는 실패한다.
   추가 테이블을 유지한 채 돌아갈 수 있는 기존 기능 + `0016` 호환 이미지를 별도 검증한다.
