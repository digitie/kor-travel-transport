# 공항 주차요금 실가용성 조사

기준: 2026-10-28, `kor-travel-transport` 새 릴리스 작업 분기. 초기 소스 조사 뒤 Root가 승인한 KAC SDK 읽기 1회와 저장 규칙의 읽기 전용 집계 1회를 수행했다. 키는 컨테이너 RAM 안에서만 전달했으며 값·URL·원문 응답·예외 본문은 출력하거나 저장하지 않았다. 운영 변경·수집 실행·설정 변경은 0이다.

## 초기 운영·소스에서 확인한 원인

아래는 수정 전 상태다. 보완된 제품 계약과 남은 검증은 마지막 절에서 구분한다.

- R10의 김포공항 소형 요금 요청은 저장 규칙 없음으로 `supported=false`였다. 당시 활성 소스는 `kac_parking,incheon_parking,incheon_fee`로 `kac_fee`가 없다. 계산 알고리즘 예외로 단정할 근거가 없다.
- `Settings.enable_fee_collection`의 기본값과 운영 예시 설정은 `false`다. 이 값이 참일 때 기존 공항 수집 작업에서 인천을 제외한 공항의 `kac_fee`를 조회한다.
- 고정한 `python-krairport-api` 커밋 `d6a1285111883f6942ba2cedafd2efcdcbef037b`는 `AirportParkingFee/parkingfee` 원문 조회를 지원한다. typed `ParkingFee`는 휴일·단위·무료 필드가 없어 현 수집기가 원문 경로를 사용한다. 휴일/분당 요금을 새 HTTP 코드로 구현할 필요가 없다.
- KAC 주차·요금은 현재 공통 쿼터 유예를 따른다. 주차 조회에서 한도 오류가 나면 같은 수집의 요금 루프도 건너뛴다. 인천 요금은 별도 소스다. 활성화만으로 첫 수집 성공을 약속할 수 없다.
- 기존 API는 lot별 규칙이 없으면 공항 공통 규칙을 적용한다. lot를 생략하면 공통 규칙이 없는 경우 가장 작은 lot ID의 규칙을 대신 쓰므로, 실제 요청한 주차장이 없는 공항 단위 가격이 만들어질 수 있다.
- 저장기가 이름 있는 요금 규칙의 주차장을 매칭하지 못해도 `parking_lot_id=NULL`로 저장한다. 이는 특정 주차장 요금이 다른 주차장 공통 요금으로 노출될 위험이다. 인천 접두어 매칭 실패도 같은 위험이 있다.
- 계산기는 평일·휴일 규칙이 모두 없으면 `ValueError`를 던진다. 현재 route에 이 예외 대응이 없어 불완전 수집을 정상적인 미가용 응답으로 전달하지 못한다.

## 공식 요금 정책과 현재 계산기의 차이

[한국공항공사 김포 주차안내](https://www.airport.co.kr/gimpo/cms/frCon/index.do?CONTENTS_NO=2&MENU_ID=1360), [이용안내](https://www.airport.co.kr/gimpo/cms/frCon/index.do?CONTENTS_NO=1&MENU_ID=1360)를 2026-10-28 조회했다.

- 공식 소형 요금은 월~목과 금~일·법정공휴일을 구분한다. 현재 `resolve_day_type`는 토·일만 휴일로 분류하고 공휴일 자료를 사용하지 않는다.
- 이용안내는 입차 후 10분 이내 출차를 무료로 설명한다. 현재 계산기는 저장된 무료 분을 모든 체류 시간에서 뺀다. 무료 이내 출차와 기본요금 시작 전 차감은 다른 정책이다.
- 공식 요금은 1일을 24시간으로 설명하고 추가 일에 반복 적용한다. 현재 계산기는 한국 자정마다 분할하여 기본요금과 무료시간을 새로 적용한다. 예를 들어 자정 전후 20분 체류를 두 번 계산할 수 있다.
- 공식 페이지는 주차장별 상이한 요금을 경고한다. 이름 매칭 실패를 공통 요금으로 바꾸거나 임의 주차장을 선택해서는 안 된다.
- 금액을 코드에 입력하지 않는다. 제공자에서 저장한 규칙과 검증된 정책으로 계산하며, 할인 증빙·미지원 차종·정책 불명확성을 결과에서 분리해야 한다.
- 공휴일이 포함된 24시간 구간의 기준일/혼합 요율과 API `parkingFreeM`의 정확한 의미는 원문 필드 설명 및 실제 제공자 응답을 추가 확인해야 한다. 공식 페이지에 없는 해석을 사실로 확정하지 않는다.

## 보완 제품 계약

1. 공항/주차장/차량별 규칙 선택과 가용성 판단을 독립 서비스에 둔다. lot 입력이 없고 여러 가격이 존재하면 주차장 선택을 요구한다. 다른 lot의 규칙으로 계산하지 않는다.
2. 계산 응답에 미가용 사유를 구분한다: 수집 비활성, 규칙 없음, 규칙 불완전, 주차장 선택 필요, 정책 확인 필요. 실제 공항·차량·주차장·기준 규칙 시각과 공식 요금 링크를 제공한다. API와 관리자 UI가 같은 계약을 소비한다.
3. 관리자 계산기는 선택한 주차장의 실제 지원 상태를 표시하고, 금액 대신 의미 없는 미지원 결과를 계산 성공으로 다루지 않는다. 필수 안내는 제목 옆 정보 버튼에 모은다.
4. 수집기의 이름 있는 규칙은 정확히 매칭된 lot에만 저장한다. 이름이 없는 진짜 공항 공통 규칙만 `NULL`로 허용한다. 실패/미매칭 수는 수집 결과에서 확인할 수 있어야 한다.
5. KAC 활성화 전 현재 서비스 승인/쿼터/규칙 커버리지를 제한된 읽기 검증으로 확인한다. 운영 변경은 Root의 정상 배포 절차로 진행하며, 주기 수집으로 규칙이 저장되는 것을 확인한다.
6. 날짜·24시간·무료 정책의 미확인 부분을 확인한 뒤 계산기를 고친다. 공휴일 조회 오류를 평일로 가정하지 않는다. 할인율을 모르면 일반 요금을 반환하고 할인 적용으로 표시하지 않는다.

## 제공자 작업 공간

형제 저장소의 원래 체크아웃은 기존 미커밋 변경이 있어 읽기만 했다. 별도 작업 공간에서
`codex/kac-fee-field-parity`를 분기해 typed 필드를 보완하고 PR #13으로 검증한다.
Transport는 해당 라이브러리를 정확 commit으로 고정하며 공급자 의미를 backend에서 다시 파싱하지 않는다.

## 검증 계획

- 저장: 미매칭 lot 요금의 공통 오염 방지, 인천 층별 접두어의 복수 매칭, 다른 공항 lot 격리, 실제 공통 규칙 보존.
- 선택/API: lot별 우선/공통 fallback, lot미지정 다중 가격 거절, 불완전 규칙의 200 미가용, 잘못된 lot의 404, 수집 OFF/규칙 없음 구분.
- 계산: 금요일/평일/법정공휴일, 자정 전후 짧은 체류, 24시간 경계, 무료 허용 범위 양옆, 단위 반올림, 일 최대 요금, 할인 미반영 안내.
- WSL 직접 테스트와 WSL Docker 테스트 뒤 PC/모바일에서 실제 가용 lot 계산 및 불가 lot 안내 확인. 운영 원본은 48시간·통계는 영구 보존하며 요금 규칙은 원본 정리 대상에 넣지 않는다.

## 추가 실증으로 확정한 내용

- 승인된 KAC 읽기: 쿼터 차단 아님을 확인한 뒤 `KrairportClient(..., timeout=20, retries=0, max_rps=1).kac_raw_items("AirportParkingFee", "parkingfee", {"pageNo":1,"numOfRows":50,"schAirportCode":"GMP"})`를 한 번 호출했다. 결과는 4행이며 소형 평일·휴일의 무료/기본/추가/최대요금 필드가 모두 존재하고 정수형이었다. 새 조회·저장은 하지 않는다.
- 실제 요금 이름: `국내선 제1주차장`, `국제선 주차장`, `화물청사 주차장`, `국내선 제2주차장(일반/예약)`. 실시간 현황 이름과 다르므로 정확한 도메인 연결이 필요하다. 국제선은 공식 요금표에서 같은 지하/빌딩 두 곳에만 연결한다.
- SDK 1회 영수증: `/var/tmp/transport-gmp-fee-readonly-0e75acb93634/result.json`. 운영 컨테이너의 ID/이미지/release/시작시각/건강 전후 동일, 소유 wrapper 실제 종료 0, 잔여 소유 자식·신호 0이다. 앞선 OCI label 가드 중단은 HTTP 0이며 원본을 보존했다.
- 저장 커버리지: 40행 모두 인천이며 김포·김해·제주는 0행이다. 인천 36행은 단기 층별 lot에 연결되어 있고 4행은 이름 매칭 실패가 공통 규칙으로 저장된 위험 행이다. `enable_fee_collection=false`, `enable_incheon_fee_collection=true`다.
- 커버리지 영수증: `/var/tmp/transport-fee-coverage-readonly-2d07d8b08acb/result.json`. 읽기 전용 트랜잭션이며 provider HTTP·운영 변경 0, 전후 운영 지문 동일, 실제 종료·자식 정리 확인이다. 원행 삭제·백필은 하지 않았다.
- Root가 기존 R10 공개 DTO에서 투영한 실제 인천 lot는 `T1 장기 P1 주차장`, `T1 장기 P1 주차타워`, `T2 P1 장기주차타워`, `T1 P5 예약주차장`, `T2 예약 주차장` 등이다. `T1 장기주차장` 같은 요금표 접두어와 다르므로 확인된 터미널·분류(short/long/reserved)로 연결한다. 새로운 DB/HTTP 조회는 하지 않는다.

## 공식 웹 계산기 경계 검산

김포 공식 페이지의 자바스크립트는 브라우저에서 요금을 계산하지 않고 공개 `getParkingPrice.do`로 입력을 보낸다. 실제 폼의 공항/주차장/차종/일반요금 조건을 익명으로 조회한 결과다. 운영 키를 쓰지 않으며 금액을 제품에 하드코딩하지 않는다. 공식 계산기 자체도 실제 요금과 차이가 있을 수 있다고 안내한다.

| 국내선 1, 소형, 할인 없음 | 공식 반환 금액 |
|---|---:|
| 2026-11-05 목 09:00 → 11-06 금 09:00 | 20,000원 |
| 2026-11-05 목 23:50 → 11-06 금 00:10 | 1,000원 |
| 2026-11-06 금 09:00 → 11-07 토 12:00 | 36,000원 |
| 2026-11-05 목 09:00 → 11-06 금 09:05 | 20,500원 |
| 2026-11-05 목 09:00 → 같은 날 09:10 | 0원 |
| 2026-11-05 목 09:00 → 같은 날 09:11 | 1,000원 |

따라서 자정 분할과 매 24시간 기본요금 재부과를 모두 피해야 한다. 처음에만 기본요금·회차 무료를 적용하고, 다음 24시간 구간은 추가 단위요금과 해당 구간 최대요금을 적용한다. 24시간 구간 시작일의 요율을 사용하며 공휴일 월별 조회 실패를 평일로 바꾸지 않는다. 최초 조사에서 미확인으로 남긴 금/토 혼합 체류 제한은 위 근거로 해소하여 지원을 유지한다.

## 구현과 남은 수용

활성화 전 호출예산 검토에서 기존 루프는 설정한 KAC 공항마다5분에 한 번씩 요금표를 조회하는
구조임을 확인했다. 정적인 요금표에 같은 호출을 반복하지 않도록 기존 raw 기록 기반의 내부
성공24시간·실패4시간 유예와 요금 SDK 즉시 재시도0을 추가한다. 실제 서비스 키별 허용량을
이론값으로 단정하지 않으며, 기존 전역 quota 차단과 실제 첫 자연 수집의 저장 결과를 별도로 확인한다.
기존 공항 job·DB 구조를 유지하고 원문 계약 표지는 provider 요청에 포함하지 않는다.

- SDK는 실제 필드 이름과 양 차종의 평일·휴일 전체 필드를 nullable 모델로 제공한다. 누락/0을 구별하고 음수·소수는 오류, 손상된 천단위 쉼표는 `None`으로 남긴다. 공급자 정책을 모델에 추정해 넣지 않는다.
- Transport의 KAC 소비자는 SDK typed 요금을 저장 도메인으로 옮기고 원문 항목은 감사용으로만 보존한다.
  KAC의 기존 원문 파싱은 오프라인 fixture 호환 경로로 한정한다. IIAC 요금은 typed 지원이 없어
  기존 raw 조회와 설명문 파싱을 유지하고 원천별 안전 경계에서 한 번 검증한다. 신규 HTTP wrapper는 없다.
- API는 lot별 선택, 불완전/없는/비활성/정책 미확인 규칙을 이유 코드로 구별하고 근거 시각·실제 선택 lot·공식 링크를 제공한다. 시간대 없는 입력과 366일 초과 입력은 422다. 임의 lot·잘못된 공항 lot로 요금을 만들지 않는다.
- 사전 적대적 검토에서 전량 미매칭의 잘못된 수집 성공과 인천 일최대 누락의 무제한 계산을 재현했다.
  미매칭은 정상 관측을 보존하는 부분 성공/오류로 드러내고, 인천의 불완전 원천과 과거 cap0 행은
  거절하도록 보완한다. `fee_rule_count`는 실제 삽입·갱신 적용 규칙 수다. 최종 독립 수용은 검증 원장에 기록한다.
- 주유소와 독립인 공용 요금 컴포넌트에 정보 팝업·공식 링크·미가용 다음 행동을 연결했다. 표준 텍스트를 반복 노출하지 않는다.
- 운영 KAC 활성화, 자연 수집에 의한 정상 규칙 저장, 실제 PC/모바일 계산, 통합 WSL/Docker/build/새 릴리스 배포는 Root의 후속 수용이다. OFF 안내만으로 계산 기능 완료로 간주하지 않는다.
